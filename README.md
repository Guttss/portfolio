## ✨ Funcionalidades

- Fundo animado com partículas em Canvas (`particles-bg`), reagindo ao movimento do mouse
- Efeito de brilho que segue o cursor (`cursor-glow`)
- Animações de entrada (*reveal on scroll*) usando `IntersectionObserver`
- Suporte a `prefers-reduced-motion`, desativando animações para quem prefere menos movimento
- Layout 100% responsivo
- Seções organizadas: Objetivo, Projetos, Experiência, Formação, Skills e Contato

## 🛠️ Tecnologias utilizadas

- **HTML5** - estrutura semântica do site
- **CSS3** - estilização, grid/flexbox e responsividade
- **JavaScript (Vanilla)** - animações, partículas e interatividade
- [Devicon](https://devicon.dev/) - ícones de tecnologias
